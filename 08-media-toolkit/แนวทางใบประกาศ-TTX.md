# แนวทางออกใบประกาศนียบัตรการเข้าร่วม TTX (ร่าง)

**วัตถุประสงค์:** ใช้กระบวนการ Google Forms → Google Sheets → เทมเพลตใบประกาศ → PDF/อีเมล เฉพาะเมื่อได้รับอนุมัติจากผู้จัดและทดสอบจริง

## เกณฑ์เสนอเพื่อให้ผู้จัดพิจารณา
- ลงทะเบียนเข้าร่วมและยืนยันการเข้าร่วมจริงผ่าน Zoom/บันทึกผู้ดำเนินการ
- ทำแบบทดสอบก่อน–หลัง (หากเป็นกิจกรรมการเรียนรู้) แต่ **ไม่กำหนดคะแนนผ่านเอง** จนกว่าคณะผู้จัดจะเห็นชอบ
- ใบประกาศใช้คำว่า **“เข้าร่วมการฝึกซ้อมแผนบนโต๊ะ”** ไม่ใช้ “ผ่านการรับรองความสามารถด้าน EOC” เว้นแต่มีเกณฑ์และอำนาจรับรองจริง
- ชื่อหน่วยงานผู้ออกใบประกาศ ผู้ลงนาม ตราสัญลักษณ์ เลขที่เอกสาร และวันออก ต้องได้รับอนุมัติก่อนใช้งาน

## ขั้นตอนทางเทคนิค
1. แบบลงทะเบียน: เก็บชื่อสำหรับพิมพ์ใบประกาศ หน่วยงาน อีเมลสำหรับจัดส่ง (แจ้งวัตถุประสงค์และระยะเวลาเก็บ)
2. Pre-test: ใช้รหัสผู้เข้าร่วมที่ไม่ใช่เลขบัตรประชาชน
3. ระหว่างฝึก: ผู้ดำเนินการยืนยันการเข้าร่วมจริง
4. Post-test: เก็บคำตอบเพื่อสรุปผลการเรียนรู้
5. ตรวจข้อมูลซ้ำและสะกดชื่อโดยผู้จัด; แยกคนที่ยังไม่ผ่านเกณฑ์การเข้าร่วมที่อนุมัติ
6. ใช้เทมเพลต Google Slides/Docs และ Apps Script หรือวิธีที่หน่วยงานเคยใช้สร้าง PDF
7. ตรวจตัวอย่างอย่างน้อย 3 รายการก่อนส่งจริง; ทดสอบชื่อยาว ภาษาไทย เลขที่เอกสาร และลิงก์
8. ส่งผ่านช่องทางที่ได้รับอนุมัติ โดยไม่เผยแพร่รายชื่อผู้เข้าร่วมและอีเมลบน GitHub สาธารณะ
9. จัดทำทะเบียนใบประกาศฉบับควบคุมและกระบวนการแก้ไขใบที่ผิด

## ตัวอย่างข้อความบนใบประกาศ
“ขอมอบใบประกาศนียบัตรฉบับนี้เพื่อแสดงว่า [ชื่อ–สกุล] จาก [หน่วยงาน] ได้เข้าร่วมกิจกรรมฝึกซ้อมแผนบนโต๊ะ (Tabletop Exercise: TTX) เรื่อง การเตรียมพร้อมและประสานการตอบโต้เหตุอุทกภัย ณ ช่องทางเข้าออกประเทศท่าเรือปัตตานี เมื่อวันที่ [วันที่]”

**สถานะ:** ยังไม่ได้ตรวจสอบระบบใบประกาศที่เคยทำร่วมกันและยังไม่มีหนังสืออนุมัติ/รายชื่อผู้ลงนาม จึงเป็นแนวทางร่าง ไม่ใช่ระบบออกใบประกาศที่เปิดใช้งานแล้ว
