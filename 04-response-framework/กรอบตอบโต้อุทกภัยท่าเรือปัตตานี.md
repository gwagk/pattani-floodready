# กรอบการเตรียมพร้อมและตอบโต้เหตุอุทกภัย — ช่องทางเข้าออกประเทศท่าเรือปัตตานี

**สถานะ:** ร่างเพื่อหารือกับเครือข่ายและใช้เตรียม TTX | **ฉบับ:** 0.1 | **วันที่:** 9 ตุลาคม 2569

> เอกสารนี้เป็นต้นแบบการประสานงาน ไม่ใช่คำสั่งราชการ แผนที่อนุมัติแล้ว หรือเกณฑ์แจ้งเตือนทางการ ต้องตรวจสอบอำนาจหน้าที่ รายชื่อผู้ประสานงาน เส้นทาง และทรัพยากรกับหน่วยงานเจ้าของภารกิจก่อนใช้ปฏิบัติจริง

## 1. วัตถุประสงค์และขอบเขต
พัฒนาความพร้อมรับอุทกภัยของเครือข่ายช่องทางเข้าออกประเทศท่าเรือปัตตานี โดยคงภารกิจจำเป็น คุ้มครองชีวิตผู้ปฏิบัติงาน ลูกเรือ และประชาชน รักษาความต่อเนื่องการสื่อสาร และทบทวนบทเรียนจากการซ้อมร่วมกันด้วยงบประชุมเพิ่มเติม 0 บาท ผ่าน Zoom หรือเครื่องมือที่มีอยู่

ผลลัพธ์ที่ต้องได้: (1) ผังผู้แจ้ง–ผู้ตัดสินใจ–ผู้ปฏิบัติ (2) เกณฑ์เปลี่ยนแผน A/B/C/D ที่หน่วยงานเห็นชอบ (3) บัญชีทรัพยากร/ผู้ประสานงานที่ตรวจสอบแล้ว (4) บันทึกการตัดสินใจ (5) AAR และรายการปรับปรุง SOP พร้อมผู้รับผิดชอบ

## 2. หลักฐานก่อนตัดสินใจ
ทบทวนข้อมูลน้ำท่วมจริงย้อนหลัง **3 ปี** โดยแยกวันที่/พื้นที่/ระดับน้ำ/เส้นทางที่ปิด/ผลต่อเรือและหน่วยงาน/ผลต่อการแพทย์และสื่อสาร; ณ วันที่จัดทำ **ยังไม่ได้แนบชุดข้อมูลยืนยันครบ 3 ปี** จึงห้ามใช้ตัวเลขสมมติเป็นสถิติจริง

แหล่งเฝ้าระวัง: กรมอุตุนิยมวิทยา (ประกาศฝนและพยากรณ์), หน่วยงานวัดระดับน้ำต้นทาง (สถานี เวลา แนวโน้ม), รายงานพื้นที่จากหน่วยงานท้องถิ่น/ท่าเรือ, ข้อมูลเส้นทางและความปลอดภัย, FloodThai เป็นแหล่งประกอบ **ไม่ใช่แหล่งสั่งการหลัก**. บันทึกเวลาประกาศและเวลาที่ตรวจพบทุกครั้ง

## 3. โครงสร้างประสานงาน (บทบาทเบื้องต้น ต้องยืนยัน)
| หน่วยงาน/กลุ่ม | ข้อมูลที่ให้ | การตัดสินใจ/การกระทำตามอำนาจจริง |
|---|---|---|
| คณะกรรมการช่องทางเข้าออกประเทศ/ฝ่ายเลขานุการด่านควบคุมโรคฯ | รวบรวมภาพรวม แจ้งประชุม ประสานเหตุด้านสาธารณสุข | เสนอแนวทางต่อผู้มีอำนาจ; ไม่ใช่ผู้สั่งการแทนทุกหน่วย |
| ผู้บริหาร/ผู้รับผิดชอบพื้นที่ท่าเรือ | ความปลอดภัยพื้นที่ ท่าเทียบ ทางสัญจร | กำหนดข้อจำกัดการใช้พื้นที่ตามอำนาจ |
| เจ้าท่า/หน่วยงานกำกับการเดินเรือ | สถานะร่องน้ำ การเดินเรือ เรือขอเข้า | พิจารณาการเดินเรือ/เข้าเทียบท่าตามกฎหมายและหน้าที่ |
| ตรวจคนเข้าเมือง | สถานะบุคคลเข้าออกประเทศ | ดำเนินงานด้านคนเข้าเมืองตามอำนาจ |
| ศุลกากร | สถานะพิธีการและสินค้า | ดำเนินพิธีการ/มาตรการตามอำนาจ |
| ประมง/PIPO/ผู้ประกอบการ | รายชื่อเรือ ลูกเรือ ความจำเป็นด้านท่าและแรงงาน | แจ้งเรือ ประสานการปฏิบัติที่ปลอดภัย |
| สสจ./โรงพยาบาล/EMS | การเจ็บป่วย เตียง รถพยาบาล เส้นทางส่งต่อ | ประเมินและดูแลผู้ป่วยตามระบบบริการ |
| ปภ./อำเภอ/เทศบาล/หน่วยกู้ภัย | ระดับเหตุ เส้นทางปลอดภัย ศูนย์พักพิง ทรัพยากร | สนับสนุนการจัดการภัยตามอำนาจ |
| ตำรวจ/จราจร/ฝ่ายความมั่นคง | ความปลอดภัย เส้นทาง การอำนวยความสะดวก | จัดการตามภารกิจและคำสั่งที่ชอบด้วยกฎหมาย |
| ผู้ให้บริการสื่อสาร/ไฟฟ้า | สถานะระบบสำรอง | แจ้งระยะเวลาฟื้นฟูและทางเลือก |

**ข้อห้าม:** อย่ากำหนดชื่อบุคคล เบอร์ส่วนตัว หรือความสามารถทรัพยากรที่ยังไม่ตรวจสอบลงในฉบับเผยแพร่สาธารณะ

## 4. ขั้นตอนปฏิบัติร่วม 8 ขั้น
1. **ตรวจพบ:** ระบุผู้แจ้ง แหล่งข้อมูล เวลา ตำแหน่ง และระดับความเชื่อมั่น
2. **ยืนยัน:** ตรวจข้ามแหล่ง โดยแยกข้อมูลพยากรณ์จากข้อมูลตรวจวัดจริง
3. **ประเมิน:** ชีวิตคน เส้นทาง พื้นที่ปฏิบัติงาน เรือที่ได้รับผลกระทบ ไฟฟ้าและสื่อสาร
4. **แจ้งเครือข่าย:** ส่ง SITREP สั้นชุดเดียว ระบุสิ่งที่รู้/ไม่รู้/ต้องการการตัดสินใจ
5. **ตัดสินใจ:** ผู้มีอำนาจแต่ละหน่วยยืนยันข้อจำกัดและการดำเนินงานของตน
6. **ปฏิบัติ:** มอบหมายผู้รับผิดชอบ กำหนดเวลาตรวจกลับ และทรัพยากรสำรอง
7. **ติดตาม:** ปรับ SITREP และบันทึกการตัดสินใจเมื่อมีเหตุเปลี่ยน
8. **คืนสภาพ:** ตรวจความปลอดภัย ทบทวนบทเรียน ปรับ SOP และปิดเหตุโดยผู้มีอำนาจ

## 5. แผน A/B/C/D — บันไดลดระดับบริการ
| แผน | สภาพ | แนวทาง |
|---|---|---|
| **A ปกติ/เฝ้าระวัง** | ระบบหลักใช้ได้ เส้นทางปลอดภัย | เฝ้าระวัง ซักซ้อมช่องทางสื่อสาร ตรวจทรัพยากร |
| **B สะดุดบางส่วน** | น้ำเริ่มกระทบเส้นทางหรือระบบบางส่วน | ลดงานไม่จำเป็น ใช้ระบบสำรองในพื้นที่ ปรับตารางเรือ/งาน |
| **C สะดุดรุนแรง** | เส้นทางหลักหรือระบบสื่อสารใช้ไม่ได้บางช่วง | ใช้สถานที่/เส้นทาง/วิธีสื่อสารสำรองที่ตรวจความปลอดภัยแล้ว ประสานหน่วยงานภายนอก |
| **D ภารกิจขั้นต่ำ/อพยพ** | เสี่ยงชีวิต พื้นที่ไม่ปลอดภัย หรือไม่สามารถคงงานสำคัญ | หยุดงานที่เสี่ยง อพยพตามอำนาจและแผนความปลอดภัย รักษาเฉพาะภารกิจวิกฤตจากจุดที่ปลอดภัย |

**เกณฑ์เปลี่ยนแผนที่ต้องตกลงร่วมกัน:** ความปลอดภัยเส้นทางเข้า–ออก, ระดับน้ำ/แนวโน้มจากสถานีที่ระบุ, การเข้าถึง EMS, ไฟฟ้า, การสื่อสาร, จำนวนเจ้าหน้าที่พร้อมปฏิบัติ, สถานะเรือและผู้โดยสาร/ลูกเรือ. **ยังไม่กำหนดตัวเลขระดับน้ำเป็นเกณฑ์จริง** เพราะต้องอาศัยหลักฐานพื้นที่และการอนุมัติ

## 6. แบบฟอร์ม SITREP ย่อ
- เลขที่รายงาน / วันเวลาออก / ผู้รายงาน / ช่องทางยืนยัน
- เหตุการณ์และพื้นที่ที่ได้รับผลกระทบ (ระบุว่า *ยืนยันแล้ว* หรือ *รอตรวจสอบ*)
- ผลกระทบต่อชีวิต สุขภาพ เรือ การเดินทาง ไฟฟ้า สื่อสาร
- แผนปัจจุบัน A/B/C/D และเหตุผล
- มติ/การตัดสินใจ: ใครตัดสินใจ เมื่อใด ตามอำนาจใด
- งานที่มอบหมาย: หน่วยงาน–งาน–กำหนดส่ง–วิธีรายงานกลับ
- สิ่งที่ต้องการสนับสนุน / เวลารายงานครั้งถัดไป

## 7. โปรโตคอลสื่อสารและความต่อเนื่อง
ช่องทางหลัก: กลุ่มประสานงานที่หน่วยงานอนุมัติ + ประชุม Zoom สำหรับ TTX; ช่องทางสำรอง: โทรศัพท์/ข้อความ/วิทยุ **เฉพาะระบบและความถี่ที่ได้รับอนุญาต**. จัดลำดับข้อความเป็น ด่วนชีวิต > คำสั่ง/ข้อจำกัดพื้นที่ > ทรัพยากร > ข่าวสารทั่วไป. ใช้รหัสเหตุการณ์และเวลารายงาน ไม่ส่งข้อมูลสุขภาพหรือข้อมูลระบุตัวบุคคลผ่านช่องทางสาธารณะ

หากสื่อสารล่ม: ใช้รายการผู้ประสานงานฉบับควบคุม, นัดเวลาเช็กอิน, บันทึกการตัดสินใจออฟไลน์ และส่งซ้ำเมื่อระบบกลับมา. การเผยแพร่ข่าวสาธารณะต้องผ่านผู้รับผิดชอบสื่อสารที่หน่วยงานกำหนด

## 8. ความปลอดภัยและจริยธรรม
ชีวิตมาก่อนทรัพย์สิน; ห้ามฝ่ากระแสน้ำหรือสั่งให้เดินทางบนเส้นทางที่ไม่ปลอดภัย; ไม่ให้บุคลากรปฏิบัติงานลำพังในพื้นที่เสี่ยง; ไม่เผยแพร่ข้อมูลผู้ป่วย/ลูกเรือรายบุคคล; ไม่สวมบทผู้มีอำนาจสั่งการแทนหน่วยงานอื่น
