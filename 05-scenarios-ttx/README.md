# 05 — Scenarios & Tabletop Exercise

The TTX will be designed for **participation, not fault-finding**.

Principle:
> Every participating organization should have a meaningful role in the scenario.

Planned materials:
- Master scenario
- Timeline
- Inject cards
- Facilitator guide
- Participant workbook
- Agency-specific prompts
- Expected actions / discussion points
- Decision log
- Homework assignments
- Exercise evaluation form

Typical prompt:
**Who knows first → who reports → who decides → who acts → what resource is used → who supports → what happens if the primary method fails?**
