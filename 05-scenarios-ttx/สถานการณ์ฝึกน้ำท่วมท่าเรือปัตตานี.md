# สถานการณ์ฝึกบนโต๊ะ (TTX): น้ำท่วมกระทบช่องทางเข้าออกประเทศท่าเรือปัตตานี

**ฉบับร่าง 0.1 | 9 ตุลาคม 2569 | รูปแบบ:** Zoom | **งบประชุมเพิ่มเติม:** 0 บาท | **ระยะเวลาตัวอย่าง:** 90–120 นาที

> **ทุกเหตุการณ์ เวลา ระดับน้ำ จำนวนผู้ป่วย และสถานะเรือด้านล่างเป็นข้อมูลสมมติเพื่อฝึก** ไม่ใช่รายงานเหตุการณ์จริง และไม่ใช่เกณฑ์แจ้งเตือนที่ผ่านการรับรอง

## เป้าหมายการฝึก
1. ทดสอบการแจ้งเหตุข้ามหน่วยงานโดยไม่สับสนว่าใครมีอำนาจสั่งการ
2. ทดสอบการเปลี่ยนแผน A→B→C→D และการคืนสู่ A ตามสถานการณ์
3. รักษาความต่อเนื่องของงานจำเป็นในช่องทางเข้าออกประเทศและความปลอดภัยของลูกเรือ
4. ทดสอบการประสานการแพทย์ฉุกเฉิน การเดินเรือ เส้นทางและระบบสื่อสาร
5. เก็บช่องว่างเพื่อแก้ SOP หลังการฝึก ไม่ใช่หาคนผิด

## ผู้เข้าร่วมที่เสนอ
เลขานุการคณะกรรมการช่องทางฯ/ด่านควบคุมโรคฯ, ผู้รับผิดชอบพื้นที่ท่าเรือ, เจ้าท่า, ตรวจคนเข้าเมือง, ศุลกากร, ประมง/PIPO, สสจ./โรงพยาบาล/EMS, ปภ./อำเภอ/ท้องถิ่น, ตำรวจ/จราจร, ผู้ประกอบการเรือ. **ให้แต่ละหน่วยยืนยันผู้แทนและขอบเขตอำนาจจริง**

## กติกาและบทบาท
- **Facilitator:** อ่านเหตุการณ์และถามคำถาม ไม่เฉลยหรือสั่งการแทน
- **Controller:** ส่ง Inject ตามลำดับและควบคุมเวลา
- **Recorder:** บันทึกคำตอบ หน่วยรับผิดชอบ เวลา และประเด็นที่ยังไม่ตกลง
- **Evaluator:** ตรวจความครบถ้วนการสื่อสาร ความปลอดภัย การตัดสินใจ และแผนสำรอง
- **ผู้แทนหน่วยงาน:** ตอบเฉพาะภารกิจตนเอง และระบุจุดที่ต้องประสานหน่วยอื่น

## Master Scenario
ปลายฤดูฝน มีฝนตกต่อเนื่องหลายวันในพื้นที่ลุ่มน้ำปัตตานีและบริเวณท่าเรือ สถานีตรวจวัดบางแห่งรายงานระดับน้ำสูงขึ้น ถนนเชื่อมพื้นที่ท่าเรือเริ่มมีน้ำขัง ขณะเดียวกันมีเรือประมงและเรือพาณิชย์ที่ต้องประสานงานตามขั้นตอนช่องทางเข้าออกประเทศ เครือข่ายต้องประเมินความเสี่ยงโดยไม่หยุดภารกิจสำคัญโดยไร้เหตุผล และไม่ฝืนปฏิบัติงานเมื่อไม่ปลอดภัย

## คำถามมาตรฐานสำหรับทุก Inject
**ใครรู้ก่อน → แจ้งใคร → ใครยืนยัน → ใครมีอำนาจตัดสินใจ → ใครลงมือ → ใช้ทรัพยากรอะไร → ใครสนับสนุน → ถ้าวิธีหลักล้มเหลวจะทำอย่างไร → รายงานกลับเมื่อใด**

- หน่วยงานเจ้าของอำนาจและผู้ตัดสินใจ:
- งานที่สั่งการ/ประสาน: ผู้รับผิดชอบ–เส้นตาย–ผลที่คาดหวัง:

- ความเสี่ยงที่ยอมรับไม่ได้และวิธีลด:

## เกณฑ์ประเมินการฝึก (เสนอ; ไม่ใช่มาตรฐานที่รับรอง)
ให้ผู้ประเมินบันทึก **มีหลักฐาน / บางส่วน / ไม่พบหลักฐาน / ไม่เกี่ยวข้อง** ใน 6 ด้าน: (1) ยืนยันข้อมูลและเวลา (2) เคารพอำนาจหน้าที่ (3) คุ้มครองชีวิต (4) ประสานข้ามหน่วย (5) มีแผนสำรอง (6) ติดตามผลและสื่อสาร. หลีกเลี่ยงการให้คะแนนตัวบุคคล

## AAR หลังฝึกและการพัฒนา SOP
1. **What was expected?** สิ่งที่คาดหวังจากแผน
2. **What happened?** สิ่งที่ผู้เข้าร่วมตัดสินใจจริงในการฝึก
3. **Why different?** ช่องว่างด้านข้อมูล อำนาจ บุคลากร ทรัพยากร หรือสื่อสาร
4. **What next?** มาตรการแก้ไข ผู้รับผิดชอบ กำหนดเวลา และหลักฐานตรวจปิด

ตัวอย่างรายการปรับปรุง: ผังโทรศัพท์ฉุกเฉินฉบับควบคุม, แบบ SITREP กลาง, ตารางผู้แทนสำรอง, แผนที่เส้นทางที่ตรวจแล้ว, ขั้นตอนส่งต่อผู้ป่วยเมื่อเส้นทางหลักถูกตัด, ข้อความสื่อสารสาธารณะสำเร็จรูป, เกณฑ์เปลี่ยน A/B/C/D ที่ได้รับอนุมัติ

## ข้อควรระวัง
ไม่ใช้ชื่อผู้ป่วยจริง เลขประจำตัว เบอร์ส่วนตัว หรือข้อมูลที่มีข้อจำกัดด้านความมั่นคงในเอกสาร GitHub สาธารณะ; ไม่อ้างว่า Inject เป็นเหตุการณ์จริง; ไม่ถือว่าผลการฝึกเท่ากับการรับรองแผน; ต้องทบทวนข้อกฎหมายและ SOP ของหน่วยงานก่อนใช้งานจริง
