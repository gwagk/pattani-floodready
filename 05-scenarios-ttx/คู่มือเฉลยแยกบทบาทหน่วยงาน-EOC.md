# คู่มือเฉลย TTX ตามบทบาทหน่วยงาน และการเชื่อมต่อ EOC

**ร่างเพื่ออภิปรายหลังซ้อม | 9 ต.ค. 2569** — ไม่ใช่คำสั่งหรือ SOP ที่รับรองแล้ว

## หลักการเฉลย
หลังจบ Inject ทั้งหมด ผู้ดำเนินการเปิดเฉลยโดยแยก **สิ่งที่ควรตรวจสอบ → ผู้รับผิดชอบตามอำนาจ → หน่วยสนับสนุน → ผลลัพธ์/หลักฐาน → แผนสำรอง** ไม่ให้คะแนนว่าใคร “ผิด” โดยไม่อ้างกฎหมายหรือแผนจริง เฉลยมีได้มากกว่าหนึ่งแนวทางหากปลอดภัย ถูกอำนาจ และตรวจสอบได้

**สำคัญ:** รายชื่อด้านล่างเป็น *บัญชีบทบาทเบื้องต้น* จากการออกแบบ TTX ยังไม่ใช่รายชื่อครบถ้วนตามหนังสือเชิญประชุม/บัญชีแนบ ซึ่งยังต้องตรวจสอบต้นฉบับก่อนกำหนดผู้รับผิดชอบรายหน่วย

## EOC คืออะไรในบริบทการฝึก
ศูนย์ปฏิบัติการฉุกเฉิน (Emergency Operations Center: EOC) เป็นกลไกสนับสนุนการบริหารเหตุ: รับและวิเคราะห์ข้อมูลสถานการณ์, สร้างภาพสถานการณ์ร่วม, สนับสนุนการตัดสินใจของผู้มีอำนาจ, ประสานทรัพยากรและการสื่อสาร, ติดตามงานและวางแผนระยะต่อไป **ไม่ใช่การตั้งผู้บังคับบัญชาใหม่เหนือทุกหน่วยโดยอัตโนมัติ**. แยก EOC (ประสาน/สนับสนุน) จากการบัญชาการเหตุการณ์ในพื้นที่และจากอำนาจตามกฎหมายของแต่ละหน่วย

## ผังหน้าที่ EOC แบบประยุกต์ (ต้องปรับตามโครงสร้างจริง)
- **ผู้อำนวยการ/ผู้มีอำนาจตามแผน:** กำหนดวัตถุประสงค์ อนุมัติการดำเนินการภายใต้อำนาจที่มี
- **ประเมินสถานการณ์/วางแผน:** รับข้อมูลที่มีเวลาและแหล่งอ้างอิง, ทำ SITREP, คาดการณ์ความเสี่ยง
- **ปฏิบัติการ/ประสานงาน:** ติดตามภารกิจแต่ละหน่วย, บันทึกงานค้าง, เชื่อมเจ้าของพื้นที่
- **ส่งกำลังบำรุง:** ประสานรถ เครื่องมือ สื่อสาร ไฟฟ้า พื้นที่สำรองตามทรัพยากรที่ยืนยันแล้ว
- **สื่อสารความเสี่ยง:** ข้อความกลางที่ได้รับอนุมัติ, แก้ข่าวลือ, ปกป้องข้อมูลส่วนบุคคล
- **ธุรการ/บันทึก:** บันทึกการตัดสินใจ การมอบหมาย ค่าใช้จ่ายตามระบบของหน่วยงาน และ AAR
หน่วยงานอาจควบรวมหน้าที่เมื่อกำลังคนน้อย; ห้ามแต่งตั้งอำนาจใหม่ด้วยเอกสารฝึก

## เฉลยตาม Inject
| Inject | แกนเฉลย | สิ่งที่ต้องมี |
|---|---|---|
| I-01 ฝนหนัก | ตรวจประกาศและข้อมูลวัดจริงแยกกัน; ฝ่ายสถานการณ์สรุป; ผู้มีอำนาจกำหนดระดับเตรียมพร้อม | SITREP 1 พร้อมเวลา/แหล่ง |
| I-02 ถนนท่วม | เจ้าของถนน/พื้นที่และตำรวจตรวจความปลอดภัย; ไม่สั่งให้ฝ่าน้ำ | แผนที่เส้นทางยืนยันและการแจ้ง |
| I-03 เรือขอเข้า | เจ้าท่าและผู้รับผิดชอบท่าตรวจเงื่อนไขความปลอดภัย; ตรวจคนเข้าเมือง/ศุลกากร/ประมง/ด่านฯ ดำเนินตามภารกิจ | รายการข้อจำกัดและผู้อนุญาตตามอำนาจ |
| I-04 ลูกเรือป่วย | ประเมินเร่งด่วนและส่งต่อผ่านระบบการแพทย์; ด่านฯ ประสานด้านสาธารณสุขและมาตรการตามอำนาจ | การส่งต่อที่ปลอดภัยและข้อมูลเท่าที่จำเป็น |
| I-05 ไฟ/เน็ตล่ม | เปิดช่องทางสำรองที่อนุมัติ บันทึกออฟไลน์ นัดเวลาเช็กอิน | แผนความต่อเนื่องและผู้รับผิดชอบข้อมูล |
| I-06 ข่าวลือ | ตรวจสอบข้อเท็จจริงก่อนเผยแพร่; ผู้มีอำนาจสื่อสารชี้แจงสั้นตรงกัน | ข้อความกลางและเวลาเผยแพร่ |
| I-07 EMS ผ่านไม่ได้ | ความปลอดภัยชีวิตมาก่อน; หน่วยแพทย์/พื้นที่/ปภ. ประเมินทางเลือก; ผู้มีอำนาจพิจารณาแผน D | หลักฐานความปลอดภัยและคำสั่งตามอำนาจ |
| I-08 ขอทรัพยากร | EOC ประสานคำขออย่างเป็นระบบ; เจ้าของทรัพยากรยืนยันการจัดสรร | ใบคำขอ–ผู้อนุมัติ–เวลาส่งมอบ |
| I-09 น้ำลด | ยังไม่กลับงานจนเจ้าของระบบตรวจรับความปลอดภัย | เช็กลิสต์คืนสภาพและผู้อนุมัติ |
| I-10 ปิดซ้อม | สรุป AAR เชื่อมช่องว่างกับเจ้าของงานและกำหนดเวลา | Improvement log |

## เฉลยแยกตามภารกิจของหน่วยงาน (เบื้องต้น)
| กลุ่ม/หน่วย | บทบาทหลักใน TTX | จุดประสาน | หลักฐานที่ควรส่ง |
|---|---|---|---|
| เลขานุการคณะกรรมการช่องทางฯ/ด่านควบคุมโรคฯ | ประสานเครือข่าย ประเมินความเสี่ยงสุขภาพและโรคติดต่อในช่องทาง | เจ้าท่า, EMS, สสจ., ตรวจคนเข้าเมือง | SITREP สุขภาพ/ข้อเสนอประสาน |
| ผู้บริหารพื้นที่ท่าเรือ | ประเมินพื้นที่และการเข้าถึงที่ปลอดภัย | เจ้าท่า, ท้องถิ่น, ผู้ประกอบการ | สถานะพื้นที่/เส้นทาง/ข้อจำกัด |
| เจ้าท่า | การเดินเรือและข้อจำกัดด้านความปลอดภัยตามอำนาจ | ท่าเรือ, เรือ, PIPO | สถานะเรือ/ข้อจำกัด/การแจ้ง |
| ตรวจคนเข้าเมือง | กระบวนการคนเข้าออกประเทศตามอำนาจ | ด่านฯ, เจ้าท่า, เรือ | ทางเลือกบริการเมื่อจุดปฏิบัติงานใช้ไม่ได้ |
| ศุลกากร | กระบวนการพิธีการและสินค้า | เจ้าท่า, ผู้ประกอบการ | แนวทางต่อเนื่องงานจำเป็น |
| ประมง/PIPO | ข้อมูลเรือ ลูกเรือ และประสานผู้ประกอบการ | เจ้าท่า, ด่านฯ, ท่าเรือ | รายการเรือที่กระทบ (ใช้ข้อมูลสมมติในซ้อม) |
| สสจ./โรงพยาบาล/EMS | คัดแยก ดูแลและส่งต่อผู้ป่วย | ด่านฯ, ปภ., ตำรวจ, ท่าเรือ | เส้นทางส่งต่อและช่องทางสำรอง |
| ปภ./อำเภอ/ท้องถิ่น/กู้ภัย | ภาพรวมภัยพิบัติ การสนับสนุนพื้นที่และทรัพยากรตามอำนาจ | ทุกหน่วย | สถานะเส้นทาง/ทรัพยากร/จุดปลอดภัย |
| ตำรวจ/จราจร | ความปลอดภัยและการจราจรตามอำนาจ | ปภ., ท้องถิ่น, EMS | แผนเส้นทาง/การแจ้ง |
| ไฟฟ้า/สื่อสาร/IT | ประเมินการล่มและการคืนระบบ | ท่าเรือ, EOC, ทุกหน่วย | เวลาโดยประมาณและระบบสำรอง |
| ผู้ประกอบการเรือ | แจ้งข้อมูลที่จำเป็น ปฏิบัติตามข้อจำกัดที่ชอบด้วยกฎหมาย | เจ้าท่า, PIPO, ด่านฯ | สถานะเรือและความต้องการช่วยเหลือ |

## คำถามเปิดเฉลยหลังซ้อม
1. เหตุการณ์นี้ใครเป็นผู้รับรู้คนแรก และรายงานเข้าศูนย์อย่างไร?
2. ใครมีอำนาจตามกฎหมายจริง ไม่ใช่เพียงผู้ประสาน?
3. มีหน่วยใดถูกลืมจากวงการแจ้งเตือน?
4. หากไฟฟ้า อินเทอร์เน็ต หรือเส้นทางหลักล้มเหลว จะทำอย่างไร?
5. หลักฐานใดพิสูจน์ว่าตัดสินใจบนข้อมูลที่ยืนยันแล้ว?
6. อะไรควรแก้ SOP ใครเป็นเจ้าภาพ และจะทดสอบซ้ำเมื่อใด?

## เงื่อนไขก่อนใช้เป็นเฉลยฉบับจริง
- ตรวจหนังสือเชิญประชุมและบัญชีแนบให้ครบทุกหน่วย แล้วทำตารางจับคู่หน่วยงาน ↔ Inject ↔ ภารกิจ
- ตรวจคำสั่งมอบอำนาจและ SOP ต้นฉบับของหน่วยงาน; หากยังไม่มีให้ระบุ **รอยืนยัน**
- แยกคำตอบที่เป็นข้อกำหนดทางกฎหมายออกจากข้อเสนอเพื่อฝึก
- ให้ตัวแทนหน่วยงานทบทวนเฉลยก่อนเผยแพร่เป็นเอกสารทางการ
